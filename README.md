# Calculator

A simple browser-based calculator with a sleek, solar-style interface. The app supports basic arithmetic operations and is built using plain HTML, CSS, and JavaScript.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Decimal input and percentage calculation
- Clear and backspace controls
- Keyboard support for quick input
- Clean calculator layout inspired by a digital display

## Project Structure

- `index.html` — calculator markup and layout
- `style.css` — styling and visual design
- `script.js` — calculator logic and event handling

## Run locally

### Option 1: Open directly in the browser

1. Download or clone this repository.
2. Open `index.html` in a browser.

### Option 2: Use a local web server

```bash
cd calculator
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Usage

- Click the buttons on the calculator to perform calculations.
- You can also use your keyboard:
  - Number keys: `0-9`
  - Decimal key: `.`
  - Operators: `+`, `-`, `*`, `/`
  - Enter: `=`
  - Backspace: delete last digit
  - Escape: clear all

## Notes

This project is a lightweight front-end app meant for learning and demonstration. It is easy to extend with additional features like square root, memory functions, or scientific mode.
